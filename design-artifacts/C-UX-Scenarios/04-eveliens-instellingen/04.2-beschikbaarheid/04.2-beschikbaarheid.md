## Overview

| Property | Value |
|----------|-------|
| Purpose | Evelien markeert dagen waarop ze niet kan studeren, zodat het planningsalgoritme hier rekening mee houdt bij het inschatten van haalbaarheid en het geven van waarschuwingen |
| User Situation | Evelien weet dat er komende week een uitje is, of dat ze elke woensdag sport — ze wil dit blokkeren zodat ze geen onrealistische shortlist krijgt |
| Mental State — Hoop | Dat de app haar agenda begrijpt en geen planningswaarschuwingen geeft op dagen dat ze toch niet kan studeren |
| Mental State — Vrees | Dat ze dit elke week opnieuw moet invullen, of dat de app rekening houdt met geblokkeerde dagen als beschikbare tijd |
| Discovery Method | Via 04.1 Instellingen → "Manage blocked days →" |
| Success Criteria | Geblokkeerde dagen zijn opgeslagen; planningsalgoritme gebruikt alleen beschikbare dagen |
| Entry Points | 04.1 Instellingen → "Manage blocked days →" |
| Exit Points | Terug → 04.1 Instellingen |

### Section: Terugkerende Dagen

#### Weekdag Toggle Rij

**OBJECT ID:** `beschikbaarheid-terugkerende-dagen-weekdag-toggle-rij`

| Property | Value |
|----------|-------|
| Component | Toggle group (7 items) |
| Translation Key | `beschikbaarheid.terugkerende.dagen.weekdag.toggle.rij` |
| SE | "—" |
| EN | "Mo Tu We Th Fr Sa Su" |
| Behavior | Elke dag is onafhankelijk aan/uit te zetten; ● = geblokkeerd (donker); standaard: Sa + Su geblokkeerd; wijzigingen worden direct opgeslagen in LocalStorage; planningsalgoritme sluit geblokkeerde weekdagen uit van beschikbare studiedagen |


### Section: Specifieke Datums

#### Maandkalender

**OBJECT ID:** `beschikbaarheid-specifieke-datums-maandkalender`

| Property | Value |
|----------|-------|
| Component | Calendar grid (month view) |
| Translation Key | `beschikbaarheid.specifieke.datums.maandkalender` |
| SE | "—" |
| EN | "{month} {year}" |
| Behavior | Toont huidige maand; tik op een dag om te blokkeren/deblokkeren (toggle); geblokkeerde dagen gemarkeerd met donkere achtergrond; verleden dagen niet selecteerbaar; wijzigingen direct opgeslagen |


#### Maandnavigatie

**OBJECT ID:** `beschikbaarheid-specifieke-datums-maandnavigatie`

| Property | Value |
|----------|-------|
| Component | Previous / Next buttons |
| Translation Key | `beschikbaarheid.specifieke.datums.maandnavigatie` |
| SE | "—" |
| EN | "‹ {prev month}  {next month} ›" |
| Behavior | Navigeert één maand voor of achteruit; maximaal 6 maanden vooruit; verleden maanden niet terug zichtbaar |


### Section: Acties

#### Reset Specifieke Datums Knop

**OBJECT ID:** `beschikbaarheid-acties-reset-specifieke-datums-knop`

| Property | Value |
|----------|-------|
| Component | Text button (destructive secondary) |
| Translation Key | `beschikbaarheid.acties.reset.specifieke.datums.knop` |
| SE | "—" |
| EN | "Clear all specific dates" |
| Behavior | Verwijdert alle eenmalige geblokkeerde datums; bevestigingsdialog voor uitvoering; herhalende weekdagen blijven intact |

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Default | Pagina geopend | Sa + Su standaard geblokkeerd; geen specifieke datums | Tik weekdag of kalenderdag om te blokkeren |
| Dag geblokkeerd | Dag getikt | Dag krijgt donkere markering | Tik opnieuw om te deblokkeren |
| Dag gedeblokkeerd | Geblokkeerde dag getikt | Donkere markering verdwijnt | — |
| Reset bevestiging | "Clear all" getikt | Confirmation dialog: "Remove all {n} blocked dates?" | Bevestigen of annuleren |
