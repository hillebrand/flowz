## Overview

| Property | Value |
|----------|-------|
| Purpose | Shortlist-grootte en persoonlijke voorkeuren aanpassen zodat de app bij Eveliens studieritme past |
| User Situation | Evelien merkt dat de standaard shortlist van 3 taken niet altijd klopt voor haar en navigeert naar instellingen |
| Mental State — Hoop | De app werkt precies zoals zij dat wil, zonder aanpassingen te moeten accepteren |
| Mental State — Vrees | Dat de app star is en niet aanpasbaar, waardoor ze afhaakt |
| Discovery Method | Ze navigeert naar Instellingen via het hoofdmenu |
| Success Criteria | Shortlist-grootte en voorkeuren zijn opgeslagen |
| Entry Points | Hoofdmenu → Instellingen |
| Exit Points | Opslaan bevestigd → scenario geslaagd ✓ |
