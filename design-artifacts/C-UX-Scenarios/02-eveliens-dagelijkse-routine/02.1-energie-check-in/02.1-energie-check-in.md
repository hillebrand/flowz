## Overview

| Property | Value |
|----------|-------|
| Purpose | Energieniveau voor vandaag invullen zodat de app een passende shortlist kan samenstellen |
| User Situation | Evelien (15, VWO 3) is 's avonds aan haar bureau, telefoon in hand, klaar om te studeren |
| Mental State — Hoop | De shortlist staat direct klaar na de check-in, ze kan meteen beginnen zonder nadenken |
| Mental State — Vrees | Dat ze op een lage-energiedag niet weet wat haalbaar is en toch te veel of te weinig oppakt |
| Discovery Method | Ze opent FlowState op haar telefoon zoals elke avond — de app vraagt meteen naar haar energie |
| Success Criteria | Evelien heeft haar energieniveau gekozen en de shortlist wordt gegenereerd |
| Entry Points | Dagelijks openen van de PWA |
| Exit Points | Tikt op energieniveau → naar 02.2 Shortlist / Vandaag |
