## Overview

| Property | Value |
|----------|-------|
| Purpose | De door AI gegenereerde shortlist van 3 taken voor vandaag tonen, energieniveau verwerkt; Evelien kan taken afvinken en de dag starten |
| User Situation | Evelien heeft zojuist haar energieniveau geselecteerd op 02.1; ze verwacht nu een concreet en haalbaar takenlijstje |
| Mental State — Hoop | Dat ze precies de goede 3 taken ziet — niet te zwaar, niet te weinig — en direct kan beginnen |
| Mental State — Vrees | Dat de shortlist niet klopt (bijv. te zware taken op een lage-energiedag) of dat ze een urgente taak mist |
| Success Criteria | Evelien ziet de shortlist, vinkt taken af gedurende de avond, en sluit de app tevreden |
| Entry Points | 02.1 Energie Check-in (na keuze energieniveau) |
| Exit Points | Taakdetail (tik op taak) → 03.1; Takenoverzicht (via nav) → volledig overzicht |

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Default | Na energie-keuze | 3 taakkaarten ongeselecteerd, energiebadge zichtbaar | Tik op checkbox om taak af te vinken |
| Urgentie | ≥1 taak is morgen/vandaag deadline | Rode urgentie-banner zichtbaar bovenaan | Banner is informationeel; geen actie vereist |
| Capaciteitsdruk | Drukke periode aankomend | Oranje capaciteitsdruk-banner zichtbaar (naast of i.p.v. urgentie-banner) | Banner is informationeel; tik op banner → takenoverzicht voor volledig beeld |
| Deels afgevinkt | ≥1 maar < 3 taken checked | Afgevinkte taken dimmen (strikethrough) | Tik op resterende taken |
| Alles afgevinkt | Alle 3 taken checked | Feest-state: "You're done for today! 🎉" animatie | Optioneel extra taak toevoegen |
| Leeg (0 taken) | Geen taken beschikbaar | Lege state: "Nothing due — enjoy your free time! 🌟" | — |
