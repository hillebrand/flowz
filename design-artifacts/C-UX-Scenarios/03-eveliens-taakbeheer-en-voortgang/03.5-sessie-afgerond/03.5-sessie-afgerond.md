## Overview

| Property | Value |
|----------|-------|
| Purpose | Evelien feliciteren met de voltooide sessie en haar twee opties geven: terug naar de shortlist of een verdiende pauze starten |
| User Situation | De timer is op 0 of Evelien heeft vroegtijdig afgerond; ze is uit haar focus-modus en heeft even ruimte |
| Mental State — Hoop | Een gevoel van voldoening — ze heeft iets gedaan — en duidelijkheid over wat nu |
| Mental State — Vrees | Dat ze het momentum verliest of niet weet of ze nog iets moet doen vandaag |
| Success Criteria | Evelien kiest bewust: pauze starten of terug naar shortlist |
| Entry Points | 03.4 Actieve Sessie → timer op 0 of "Finish early" |
| Exit Points | "Take a break →" → 03.6 Pauzetimer; "Back to today →" → 02.2 Shortlist Vandaag |
