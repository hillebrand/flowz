# 03.6 Pauzetimer

## Page Metadata

| Page Number | 03.6 |
| Platform | Mobile web (PWA) |
| Page Type | — |
| Viewport | — |
| Interaction | — |
| Visibility | Private |

---

## Overview

| Property | Value |
|----------|-------|
| Purpose | Evelien een gestructureerde pauze geven na een sessie, met een timer die automatisch naar de shortlist navigeert als de pauze voorbij is |
| User Situation | Evelien heeft net een sessie afgerond en heeft een pauze gekozen; ze legt haar telefoon neer maar wil weten wanneer ze weer moet beginnen |
| Mental State — Hoop | Dat ze echt tot rust komt en de telefoon eventjes kan neerleggen zonder iets te missen |
| Mental State — Vrees | Dat de pauze te kort is of dat ze vergeet wanneer ze weer moet beginnen |
| Success Criteria | Pauzetimer telt af; navigeert automatisch naar 02.2 Shortlist Vandaag bij 0:00 |
| Entry Points | 03.5 Sessie Afgerond → "Take a break →" |
| Exit Points | Timer op 0 → auto-navigatie naar 02.2 Shortlist Vandaag; "Skip break" → 02.2 Shortlist Vandaag |
