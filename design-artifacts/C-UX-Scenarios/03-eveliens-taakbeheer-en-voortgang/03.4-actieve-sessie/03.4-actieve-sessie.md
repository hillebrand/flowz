## Overview

| Property | Value |
|----------|-------|
| Purpose | De actieve studiesessie begeleiden via een Pomodoro timer, de eerste openstaande deeltaak tonen en Evelien de mogelijkheid geven vroegtijdig af te ronden |
| User Situation | Evelien is aan het studeren; haar spullen liggen klaar en de timer is gestart. Ze heeft focus nodig en wil weten hoeveel tijd er nog is |
| Mental State — Hoop | Dat ze gefocust kan werken zonder afleiding en de deeltaak afkrijgt voor de timer afloopt |
| Mental State — Vrees | Dat ze de tijd niet bijhoudt of halverwege de sessie wordt afgeleid |
| Success Criteria | Sessie is afgerond (timer bereikt 0 of vroegtijdig beëindigd); deeltaak optioneel afgevinkt |
| Entry Points | 03.3 Sessie Voorbereiding → "Let's go →" |
| Exit Points | Timer op 0 of "Finish early" → 03.5 Sessie Afgerond |

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Actief | Sessie loopt | Timer telt af; eerste openstaande deeltaak zichtbaar | Subtaak afvinken; wachten op timer |
| Deeltaak afgevinkt | Checkbox getikt | Huidige subtaak verdwijnt, volgende verschijnt | Doorgaan met werken |
| Alle subtaken klaar | Alle subtaken afgevinkt | Deeltaak sectie verborgen; timer loopt door | Timer afwachten of vroegtijdig afronden |
| Geen subtaken | Taak heeft geen subtaken | Deeltaak sectie niet zichtbaar; alleen timer | Timer afwachten |
| Timer op 0 | Countdown bereikt 0:00 | Automatische navigatie naar 03.5 | Geen actie vereist |
