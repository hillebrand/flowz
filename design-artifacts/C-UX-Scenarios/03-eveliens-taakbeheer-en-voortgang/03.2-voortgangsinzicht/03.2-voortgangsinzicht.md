### Section: Weekoverzicht

#### Week Voortgangsbalk

**OBJECT ID:** `voortgangsinzicht-weekoverzicht-week-voortgangsbalk`

| Property | Value |
|----------|-------|
| Component | Progress bar (labeled) |
| Translation Key | `voortgangsinzicht.weekoverzicht.week.voortgangsbalk` |
| SE | "—" |
| EN | "{done}/{total} tasks done this week" |
| Behavior | Dynamic: counts tasks completed in current school week |


#### Dag Checkmarks

**OBJECT ID:** `voortgangsinzicht-weekoverzicht-dag-checkmarks`

| Property | Value |
|----------|-------|

| Translation Key | `voortgangsinzicht.weekoverzicht.dag.checkmarks` |
| SE | "—" |
| EN | "Mon Tue Wed Thu Fri Sat Sun" |
| Behavior | Shows ✓ for days with sessions, ○ for days without; current day highlighted |
