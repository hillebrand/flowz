## Overview

| Property | Value |
|----------|-------|
| Purpose | Evelien een moment geven om haar benodigdheden te verzamelen vóór de sessie begint — zo kan ze de sessie ononderbroken starten |
| User Situation | Evelien heeft op "Start session" getikt in 03.1; ze is mentaal klaar maar moet nog even haar spullen pakken |
| Mental State — Hoop | Dat ze precies weet wat ze nodig heeft en met vertrouwen kan beginnen |
| Mental State — Vrees | Dat ze halverwege een sessie moet stoppen om een schrift of boek te pakken |
| Success Criteria | Evelien heeft haar spullen, tikt op "Let's go" en de sessie start |
| Entry Points | 03.1 Taak Detail → "▶ Start session" |
| Exit Points | "Let's go →" → 03.4 Actieve Sessie; "← Back" → 03.1 Taak Detail |
