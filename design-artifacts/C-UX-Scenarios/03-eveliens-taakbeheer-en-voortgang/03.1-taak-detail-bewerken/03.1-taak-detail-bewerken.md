## Overview

| Property | Value |
|----------|-------|
| Purpose | Bestaande taak inzien en effort, deadline of complexiteit aanpassen |
| User Situation | Evelien is aan het studeren en merkt dat een taak veel groter is dan gedacht — ze wil bijstellen voordat het te laat is |
| Mental State — Hoop | Snel kunnen bijstellen en direct zien dat ze nog op schema zit |
| Mental State — Vrees | Te laat ontdekken dat de taak niet meer haalbaar is voor de deadline |
| Discovery Method | Ze tikt op een taak in haar shortlist of takenoverzicht en opent de detail-view |
| Success Criteria | Taak is opgeslagen met de bijgestelde effort/deadline |
| Entry Points | Shortlist / Vandaag of Takenoverzicht — tikt op een specifieke taak |
| Exit Points | Tikt op "Opslaan" → naar 03.2 Voortgangsinzicht |

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Default | Pagina geopend | Read-only view; Edit knop zichtbaar | Tik Edit om te bewerken |
| Bewerken | Edit knop getikt | Velden worden bewerkbaar; opslaan knop verschijnt | Pas aan + Opslaan |
| Sessie gelogd | "+ Log session" getikt | Voortgangsbalk update; knop disabled als sessies vol | — |
| Voltooid | Alle sessies gedaan | Taak toont "Done ✓"; geen sessie-knop meer | — |
