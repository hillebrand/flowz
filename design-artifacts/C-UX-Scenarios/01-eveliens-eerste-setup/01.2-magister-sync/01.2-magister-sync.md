## Overview

| Property | Value |
|----------|-------|
| Purpose | Evelien verbindt FlowState met haar Magister-account; de app haalt huiswerkopdrachten op en bereidt de importreview voor |
| User Situation | Evelien heeft zojuist op "Connect Magister" getikt; ze verwacht een snelle koppeling en heeft haar Magister-inloggegevens bij de hand |
| Mental State — Hoop | Dat de koppeling snel gaat en ze meteen haar taken ziet |
| Mental State — Vrees | Dat het technisch misgaat (fout wachtwoord, schoolnetwerk) of dat Magister te veel onzin importeert |
| Success Criteria | Magister-verbinding geslaagd, huiswerkopdrachten opgehaald, door naar Import Review |
| Entry Points | 01.1 Welkomst (primair) + dagelijkse terugkeer via app-open |
| Exit Points | Verbinding geslaagd → 01.3 Import Review |

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Default | Paginaopening | Lege invoervelden, CTA knop disabled | Typ inloggegevens |
| Ingevuld | Beide velden hebben inhoud | CTA knop enabled | Tik "Connect" |
| Laden | Na tikken CTA | Spinner + "Syncing your homework from Magister…" | Wacht op API respons |
| Fout | Verkeerde credentials of netwerk error | Rode foutmelding onder invoervelden | Herstel en probeer opnieuw |
| Dagelijkse sync | App dagelijks geopend (niet eerste keer) | Zichtbaar als tussenscherm: "Syncing…" → automatisch door | Geen actie nodig |
