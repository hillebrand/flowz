## Overview

| Property | Value |
|----------|-------|
| Purpose | Volledig overzicht van alle taken tonen — gesorteerd op urgentie/deadline; hub voor taakbeheer |
| User Situation | Evelien heeft haar eerste import voltooid en ziet nu alles samengekomen; of ze navigeert er naartoe vanuit de shortlist voor volledig overzicht |
| Mental State — Hoop | Dat ze in één oogopslag ziet wat de situatie is — geen verborgen verrassingen, alles is zichtbaar en geordend |
| Mental State — Vrees | Dat de lijst overweldigend lang is of dat ze een deadline heeft gemist |
| Success Criteria | Evelien ziet alle taken met deadline en urgentie-indicator; de lijst is opgeruimd en actiegericht |
| Entry Points | 01.4 Taak Aanmaken (na laatste import) + navigatie vanuit 02.2 Shortlist + bottom navigation |
| Exit Points | Tik op taak → 03.1 Taak Detail Bewerken; Terug naar shortlist → 02.2 |

## Layout Structure

```
+----------------------------------+
|  ☰  FlowState              👤   |  ← App header
+----------------------------------+
|  All tasks          [Filter ▾]   |  ← Paginatitel + filter
|  [☰ List] [📅 Calendar]          |  ← Weergave toggle
+----------------------------------+
|                                  |
|  🔴 URGENT                       |  ← Urgentiegroep label
|  ────────────────────────────    |
|  [ Essay English     Mon  2s ]   |  ← Taakkaart
|  [ Math exercises    Wed  1s ]   |  ← Taakkaart
|                                  |
|  🟡 THIS WEEK                    |  ← Urgentiegroep label
|  ────────────────────────────    |
|  [ History summary   Fri  1s ]   |  ← Taakkaart
|                                  |
|  🟢 UPCOMING                     |  ← Urgentiegroep label
|  ────────────────────────────    |
|  [ Biology project   +2w  3s ]   |  ← Taakkaart
|                                  |
|  [  +  New task  ]               |  ← FAB (floating action button)
+----------------------------------+
```

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Default | Met taken | Taken gegroepeerd per urgentiegroep (rood/geel/groen) | Tik taak voor detail; filter voor sortering |
| Leeg | Geen taken | "No tasks yet — great job! 🌟 Or add one manually." | Tik FAB om taak handmatig toe te voegen |
| Gefilterd | Filter actief | Alleen taken van geselecteerd vak of deadline-range | Filter-chip zichtbaar in header |
| Calendar view | Staat: Calendar view actief | Maandgrid: cellen met deadline-stippen per dag; tik op dag → taken van die dag | Tik op taakstip → detail |
