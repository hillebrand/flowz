## Overview

| Property | Value |
|----------|-------|
| Purpose | Evelien verrijkt een geïmporteerde Magister-opdracht tot een volwaardige taak — titel, aantal sessies, complexiteit, subtaken en benodigdheden |
| User Situation | Evelien doorloopt de importwachtrij één taak tegelijk; de basisdata is al ingevuld (van Magister), zij voegt haar eigen inzicht toe |
| Mental State — Hoop | Snel door de wachtrij heen — elke taak hoeft maar een paar tikken te kosten |
| Mental State — Vrees | Dat ze alles zorgvuldig moet invullen voordat ze kan beginnen (verhoogde drempel) |
| Success Criteria | Taak opgeslagen met sessies + complexiteit; wachtrij gaat door naar volgende item of eindigt bij Takenoverzicht |
| Entry Points | 01.3 Import Review (na bevestigen import) |
| Exit Points | Volgende taak in wachtrij → opnieuw 01.4 of, na laatste taak → 01.5 Takenoverzicht |

## Layout Structure

```
+----------------------------------+
|  ☰  FlowState              👤   |  ← App header
+----------------------------------+
|  Task 1 of 3                     |  ← Voortgangsindicator wachtrij
+----------------------------------+
|                                  |
|  [ Essay English             ]   |  ← Taaknaam (pre-ingevuld)
|  [ Add a description...      ]   |  ← Omschrijving (optioneel, multi-line)
|  [ English             ▼    ]   |  ← Vak (pre-ingevuld)
|  [ Due Monday 26 May         ]   |  ← Deadline (pre-ingevuld, readonly)
|                                  |
|  Sessions needed:  [ 2  ↑↓ ]    |  ← Stepper: aantal sessies
|  Complexity:    [Low][Med][High] |  ← 3-knops selector
|                                  |
|  Subtasks (optioneel):           |
|  [ + Add subtask... ]            |
|                                  |
|  Materials needed (optioneel):   |
|  [ + Add material... ]           |
|                                  |
|  [ Save & next →  ]              |  ← Primaire CTA
|  [ Skip ]                        |  ← Sla verrijking over
|                                  |
+----------------------------------+
```

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Default | Taak-aanmaak geopend | Pre-ingevulde velden van Magister, sessies=1, complexiteit=Medium | Pas aan naar eigen inschatting |
