## Overview

| Property | Value |
|----------|-------|
| Purpose | Evelien ziet het welkomstscherm en start de Magister-koppeling |
| User Situation | Evelien (15, VWO 3) is net thuisgekomen uit school, heeft even gegeten en gedronken, en zit nu aan haar bureau klaar om te beginnen met huiswerk |
| Mental State — Hoop | Meteen aan het werk kunnen — de app toont haar direct wat ze moet doen, zonder dat ze zelf een planning hoeft te maken |
| Mental State — Vrees | Dat ze eerst moet uitzoeken of de planning nog klopt voordat ze kan beginnen |
| Discovery Method | Opent de PWA voor het eerst op haar telefoon — de app die ze zelf heeft gebouwd, via URL of startscherm-shortcut |
| Success Criteria | Evelien tikt op "Verbind met Magister" en de sync start |
| Entry Points | Eerste keer openen van de PWA (verse installatie) |
| Exit Points | Tikt op "Verbind met Magister" → naar 01.2 Magister-sync |
