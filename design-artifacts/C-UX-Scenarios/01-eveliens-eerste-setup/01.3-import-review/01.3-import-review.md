## Overview

| Property | Value |
|----------|-------|
| Purpose | Evelien ziet de zojuist opgehaalde Magister-huiswerkopdrachten als een reviewlijst; ze kan zien wat er binnenkomt en bevestigt de import |
| User Situation | Magister-sync is net geslaagd; Evelien ziet voor het eerst haar huiswerk als gestructureerde lijst in de app |
| Mental State — Hoop | Dat alles er al goed uitziet en ze met één tik kan doorgaan |
| Mental State — Vrees | Dat er foute of onnodige opdrachten tussen zitten die ze handmatig moet weggooien |
| Success Criteria | Evelien bevestigt de import → huiswerkopdrachten worden beschikbaar als taak-aanmaak-wachtrij |
| Entry Points | 01.2 Magister Sync (na geslaagde verbinding) + dagelijkse sync (alleen nieuwe items) |
| Exit Points | "Import {n} tasks" → 01.4 Taak Aanmaken (eerste taak in wachtrij) |
