## Overview

| Property | Value |
|----------|-------|
| Purpose | Evelien beheert haar studiecapaciteit: standaard minuten per weekdag (macro) en overrides voor specifieke datums (meso); geblokkeerde dagen worden automatisch als 0 minuten behandeld |
| User Situation | Wil haar standaard studietijden instellen of een uitzondering invoeren (vakantie, toetsweek) |
| Success Criteria | Elke instelling slaat automatisch op; de planning-engine gebruikt deze waarden bij de volgende check-in |
| Entry Points | 04.1 Instellingen (via "Beheer beschikbaarheid →") |
| Exit Points | ← Terug naar 04.1 Instellingen |

### Section: Weekcapaciteit (NIEUW — macro-planning)

Witte kaart. Per weekdag stelt Evelien het standaard aantal beschikbare studieMinuten in. Waarde 0 = dag geblokkeerd (vervangt het bestaande weekdag-blokkeer-systeem).

| Object ID | Component | NL Content | EN Content | Behavior |
|-----------|-----------|-----------|-----------|---------|
| `04.2-weekcap-title` | Sectie-label uppercase | "WEEKCAPACITEIT" | "WEEKLY CAPACITY" | Statisch |
| `04.2-weekcap-subtitle` | Body tekst grijs | "Hoeveel minuten studeer je standaard op deze dag?" | "How many minutes do you usually study on this day?" | Statisch |
| `04.2-weekcap-grid` | 7-koloms grid, één cel per weekdag | Ma · Di · Wo · Do · Vr · Za · Zo | Mo · Tu · We · Th · Fr · Sa · Su | Elke cel toont dag-label + stepper (−/waarde/+); stapgrootte 15 min; min 0, max 300 (5 uur); waarde 0 toont "Vrij" in grijs; opslaan bij elke wijziging; persisteert in `dataStore.settings.capacity_week` |

**Stepper per dag (inline component binnen het grid):**

| Object ID | Component | NL Content | Behavior |
|-----------|-----------|-----------|---------|
| `04.2-weekcap-day-minus` | Ronde min-knop | − | Verlaagt met 15 min; floor op 0 |
| `04.2-weekcap-day-value` | Getallabel gecentreerd | "60 min" / "Vrij" | Toont waarde in minuten; 0 → "Vrij" (grijs) |
| `04.2-weekcap-day-plus` | Ronde plus-knop | + | Verhoogt met 15 min; cap op 300 min |

### Section: Datum-overrides (UITGEBREID — meso-planning)

Bestaande kalenderkaart uitgebreid: een datum kan niet alleen volledig geblokkeerd worden, maar ook een capaciteits-override (X minuten) krijgen.

| Object ID | Component | NL Content | EN Content | Behavior |
|-----------|-----------|-----------|-----------|---------|
| `04.2-overrides-title` | Sectie-label uppercase | "DATUM-OVERRIDES" | "DATE OVERRIDES" | Statisch |
| `04.2-overrides-subtitle` | Body tekst grijs | "Tik een datum aan om hem te blokkeren of een afwijkend aantal minuten in te stellen." | "Tap a date to block it or set a different number of minutes." | Statisch |
| `04.2-cal-nav-prev` | ← maand-knop | ‹ | ‹ | Vorige maand |
| `04.2-cal-month-label` | Maandnaam + jaar gecentreerd | "Juni 2026" | "June 2026" | Dynamisch |
| `04.2-cal-nav-next` | → maand-knop | › | › | Volgende maand |
| `04.2-cal-grid` | 7-koloms maandgrid | dag-nummers | day numbers | Klikbare dagen (niet verleden); kleurcodering: **grijs** = 0 min (geblokkeerd), **paars** = custom minuten override, **ring** = vandaag, **standaard** = weekcapaciteit van toepassing |
| `04.2-cal-day-picker` | Bottom sheet bij tik op datum | "Hoeveel minuten op [datum]?" + stepper + "Blokkeren" knop + "Opslaan" | "How many minutes on [date]?" | Toont stepper (15 min stappen, 0–300) + "Blokkeren" shortcut knop (→ 0 min); opslaat in `dataStore.settings.capacity_overrides[dateStr]` |
| `04.2-clear-overrides-btn` | Ghost knop onderaan kaart | "Alle datum-overrides wissen" | "Clear all date overrides" | Confirm dialog; wist `capacity_overrides`; past ook kleurcodering in grid aan |

## Page States

| State | Wanneer | Weergave |
|-------|---------|----------|
| **Leeg / standaard** | Geen overrides ingesteld | Alle weekdagen tonen standaard 60 min; kalender zonder markeringen |
| **Dag geblokkeerd** | Weekdag-waarde = 0 | Cel toont "Vrij" in grijs; kalender-dag grijs |
| **Override actief** | Datum in `capacity_overrides` | Kalenderdag paars gekleurd; bottom sheet toont huidige override-waarde |
| **Opgeslagen** | Na elke wijziging | Save toast 1,5 s zichtbaar |
